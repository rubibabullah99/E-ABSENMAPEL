Integrasi GitHub Repository

Version control & free cloud hosting

GitHub Actions Workflow Terpasang

Berkas .github/workflows/deploy.yml telah disiapkan. Begitu kode didorong ke branch main, aplikasi web otomatis live di GitHub Pages!

3 Langkah Push ke GitHub:

1

Buat Repository Baru di GitHub

Buka github.com/new dan beri nama misal: e-absen-mapel (Public).

2

Jalankan Setup Otomatis

Klik ganda berkas setup-github.bat di folder project atau jalankan perintah git di bawah.

3

Aktifkan GitHub Pages

Di repo GitHub: masuk ke Settings -> Pages -> ubah Source ke GitHub Actions.

Perintah Manual Git:

# Inisialisasi & Commit

git init

git add .

git commit -m "Initial commit: E-Absen"

git branch -M main

# Hubungkan & Dorong ke Repo Anda

git remote add origin URL_GITHUB_ANDA

git push -u origin main
